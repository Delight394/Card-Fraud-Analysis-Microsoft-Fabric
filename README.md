# Credit Card Fraud Detection Using SQL

## Project Overview
Analyzed a synthetic credit card transaction dataset using SQL in Microsoft Fabric to explore fraudulent transactions, data quality, and monthly fraud occurrences.

## Dataset
- **400 transactions**
- **7 columns**
- **Fraud rate:** 1.5%
- **Format:** CSV

## Tools
- SQL
- Microsoft Fabric
- Git & GitHub

## Analysis Performed
- Checked for missing values.
- Analyzed fraudulent vs. legitimate transactions.
- Extracted month, year, and day names.
- Investigated monthly fraud occurrences.
- Explored transaction amounts, merchant categories, locations, and failed attempts.

## Disclaimer
This project uses synthetic data for educational purposes and is not a production-ready fraud detection system.
